# IBM Bob Usage & Development Report

## Project Name
**CareerX-AI — AI Career Copilot**

## Development Environment

- **Primary development environment:** IBM Bob
- **AI-assisted development tool:** IBM Bob
- **Frontend:** React + Vite
- **Backend:** Express.js
- **Generative AI service used by the application:** Gemini API
- **Version control:** Git and GitHub

---

## 1. Project Overview
CareerX-AI is an AI-powered career guidance application designed to help students and early-career professionals understand their strengths, identify skill gaps, and plan for realistic career moves.

The project combines resume analysis, career matching, learning-roadmap guidance, and mock interview support into one workflow.

---

## 2. Role of IBM Bob
IBM Bob was used as the primary development environment and AI-assisted development tool during the creation of CareerX-AI. It supported planning, implementation, debugging, refactoring, testing, and documentation. The developer reviewed, adjusted, and verified the generated work before it was integrated into the final project.

---

## 3. Development Workflow
The process followed this pattern: idea → planning → development → AI assistance → testing → debugging → integration.

IBM Bob was used when the team needed help with architecture decisions, code generation, UI logic, backend flow design, debugging, and project documentation.

---

## 4. Frontend Development
The frontend was created in React using Vite. IBM Bob assisted with the landing page, dashboard, resume workflow, learning roadmap view, and mock interview screens, while keeping the structure aligned with the app’s career guidance goals.

---

## 5. Backend Development
The backend was built with Express.js and a Gemini-powered API route. IBM Bob helped structure the analysis endpoints, improve validation and error handling, and support the AI-driven feature flow.

---

## 6. Gemini Integration
Gemini API is the generative AI service used by the CareerX-AI application. IBM Bob was not the runtime AI model powering the app; it was the primary development environment and AI-assisted coding tool used to build and refine the system.

The server code uses Gemini to generate structured resume analysis, career guidance, interview questions, and answer feedback.

---

## 7. AI Career Features
The application includes core career-support capabilities backed by the repository evidence:

- Resume analysis and skill extraction
- Career matches and readiness signals
- Skill-gap identification
- Personalized learning roadmap generation
- AI mock interview question generation
- Interview answer evaluation and feedback

These features are implemented in the React frontend and Express backend and are supported by the Gemini prompt-based workflow in the server code.

---

## 8. Debugging and Improvement
IBM Bob was used to diagnose implementation issues, including invalid input handling, API failures, malformed AI output, and frontend state issues. The suggested fixes were reviewed and validated before being kept in the final project.

---

## 9. Documentation Support
IBM Bob helped draft the project overview, workflow explanation, and development evidence structure used in this repository. The bob_sessions folder records the supporting design and troubleshooting work.

---

## 10. Conclusion
CareerX-AI was developed with IBM Bob as the primary development environment and AI-assisted coding tool. The Gemini API provides the generative AI capabilities used by the application itself. This reflects a clear division between the development environment and the runtime AI service used by the product.
