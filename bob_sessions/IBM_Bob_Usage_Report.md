# IBM Bob Usage & Development Report

## Project Name
**CareerX – AI-Powered Career Development Platform**

## Development Environment

- **Primary IDE:** Visual Studio Code (VS Code)
- **AI Development Assistant:** IBM Bob
- **Version Control:** Git & GitHub
- **Frontend:** React + Vite
- **Backend:** Express.js
- **AI/LLM:** Google Gemini API
- **Database:** Firebase Firestore
- **Deployment:** Render

---

## 1. Project Overview
CareerX is an AI-powered career development platform designed to help students and job seekers improve their career readiness through intelligent career analysis and guided learning.

The app combines resume analysis, skill assessment, roadmap suggestions, and career preparation support into a single experience.

---

## 2. Role of IBM Bob
IBM Bob supported the team with planning, implementation support, debugging, code improvement, and documentation. The project development remained under human supervision in VS Code, while Bob accelerated the writing, analysis, and troubleshooting workflow.

---

## 3. Development Workflow
The process followed this pattern: idea → planning → development → AI assistance → testing → debugging → integration.

IBM Bob was used when the team needed help with code generation, UI structure, backend architecture, or issue diagnosis.

---

## 4. Frontend Development
The frontend was created in React using Vite. IBM Bob assisted with landing page structure, dashboard design, page flows, and UI improvements.

---

## 5. Backend Development
The backend was built with Express.js and a Gemini-powered API route. IBM Bob helped structure the analysis endpoint and improve validation and error handling.

---

## 6. AI Features
The resume analysis workflow sends extracted resume text to Google Gemini, which returns structured data about skills, experience, job fit, skill gaps, and roadmap suggestions.

---

## 7. Resume and ATS Analysis
The resume upload flow extracts text from a PDF and submits it to the AI backend. The result is used to generate personalized insights and readiness scores for the user.

---

## 8. Debugging and Improvement
IBM Bob was used to diagnose implementation issues, including API failure handling, malformed AI output, and state-level errors in the frontend. The suggested fixes were reviewed and validated before being kept in the final project.

---

## 9. Documentation Support
IBM Bob helped draft the project overview, workflow explanation, and development evidence structure used in this repository.

---

## 10. Conclusion
CareerX was developed through a combination of VS Code, human review, Git/GitHub, and AI assistance from IBM Bob. This created an efficient and practical development workflow while maintaining ownership and validation of the final product.
